# PhiArc Documentation (phiarc-docs)
Welcome to the PhiArc archive. This repository serves as the central authority for document archiving rules and naming conventions within the PhiArc ecosystem.

## Part 1. Documentation (/docs)
This section contains essential resources and guidelines for editors and contributors.

Contribution Workflow: If you are contributing academic or creative content, such as Essays or Lecture Notes, you must adhere to our standardized formatting.

Specification Path: Detailed guidelines can be found in:

phiarc-docs/docs/editor/spec/

Status Update: The official Format Direction file is currently under development and is scheduled for completion in April 2026.

## Part 2. Logs and Records (/log)
The log directory is dedicated to dynamic, frequently updated documents and historical records.

Chronological Organization: Files are primarily organized by Year.

Conditional Categorization: Within each yearly folder, documents are further categorized by their Status or Specific Condition (e.g., drafts, completed archives, or revision histories).

## Further Information
For more comprehensive details regarding specific workflows or archival policies, please refer to the individual documentation files located within the subdirectories.
